# Cola comigo

Aplicativo multiplataforma de agenda escolar, desenvolvido com .NET MAUI para Android e Windows.

## Requisitos

- .NET 10 SDK
- Workloads do .NET MAUI para Android e Windows

## Compilar

```powershell
dotnet build .\ColaComigo.csproj -f net10.0-android
dotnet build .\ColaComigo.csproj -f net10.0-windows10.0.19041.0
```

O projeto também pode ser aberto no Visual Studio com suporte ao .NET MAUI.
